# Ask Claudia

Questions for Claudia Valsells, gathered while building the new site. Answers go back to Frank.

## 1. The opening film: where is it, and which cut?

The film on the start page has no sound: the copy the site was built from is silent. Where is the version with sound (a file, a link, a page on the current site)? And which cut of the film should open the site: the one there now, or another?
